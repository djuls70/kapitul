> **Автор проекта:** Сергей Музыкин ([`@SerjMuzikin`](https://t.me/SerjMuzikin))  
> **Формат:** Двухэкранный автономный веб-прототип (`index.html` + `app.html`) для публикации на GitHub Pages.

---

## 1. О проекте

**«КАПИТУЛ»** — интеллектуальная платформа для навигации бизнеса по мерам государственной поддержки в РФ (гранты, субсидии, льготные займы под 1–7%, налоговые преференции, поручительства и инфраструктурные льготы от 1 000+ госоператоров во всех 89 регионах).

1. **Продуктовый лендинг ([`index.html`](./index.html)):**
   * Институциональный дизайн (`#F4F4F0` / `#FFFFFF` / `#0D5C46`, шрифт `Golos Text`).
   * Интерактивная витрина **28 видов господдержки** с живой двухрядной лентой и тумблером переключения в полный список.
   * Метрики охвата (`1 000+ госоператоров`, `89 регионов`, `24/7`) и переход в демо-диагностику.
2. **Интерактивное демо-приложение ([`app.html`](./app.html)):**
   * **Состояние 1 (`CJM-A-01`):** Пошаговый бриф из 6 вопросов (автокомплит по 89 субъектам РФ, отрасль, стадия развития, цель финансирования, мультивыбор особых статусов, налоговый фильтр ФНС/ФССП).
   * **Состояние 2:** Имитация скоринга по региональной и федеральной базе («Театр алгоритмов»).
   * **Состояние 3 (`CJM-A-02`):** Персональный дашборд результатов (21 найденная мера в 4 категориях, цифровой профиль ответов, динамическая открытая карточка приоритетной программы с блоком «Аналитика КАПИТУЛ» под выбранную отрасль и 3 заблокированные программы).
